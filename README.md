# JavaPR6

Практическая работа №6 — Кинофестиваль

Требования: JDK 21.

Компиляция из папки PR6_Festival_Solution:
    javac -encoding UTF-8 --release 21 -d out src/festival/*.java

Запуск:
    java -cp out festival.Main

Пункты меню:
1 — каталог; 2 — поиск; 3 — добавить оценку; 4 — просмотр по длительности;
5 — рейтинг по среднему; 6 — рейтинг по максимальной индивидуальной оценке.

Ожидаемый порядок:
Средняя оценка: 1, 3, 4, 2, 5
Лучшая оценка: 2, 5, 1, 4, 3
Исходный порядок каталога: 3, 1, 6, 2, 5, 4

В решении реализованы Strategy, сортировка по score по убыванию и ID по возрастанию,
исключение фильмов без оценок, неизменность исходного порядка каталога и отдельный
класс FestivalReport для печати результата.
